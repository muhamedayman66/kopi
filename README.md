# KOPI — موقع متابعة مصاريف ومساهمات الكافيه

موقع بسيط بيقرا ويكتب مباشرة في نفس شيت الـ Google Sheets بتاعك، بحيث كل الشركاء
يقدروا يفتحوه، يضيفوا مساهمة/مصروف/عهدة، والبيانات تتحدث لحظيًا في الشيت والعكس.

**مفيش قاعدة بيانات منفصلة** — الشيت نفسه هو قاعدة البيانات.

---

## الخطوة 1: تجهيز الشيت (Google Apps Script)

1. افتح شيت الجوجل بتاعك (نفس الشيت اللي فيه شيتات: المساهمات، المصروفات، عهدة نقدية عند الشركاء، الملخص العام).
2. من القائمة فوق: **Extensions (الإضافات) → Apps Script**.
3. هيفتحلك محرر كود جديد فيه ملف `Code.gs` فاضي (أو فيه كود قديم) — امسح كل اللي فيه.
4. افتح ملف `google-apps-script/Code.gs` من المشروع اللي بعتهولك، وانسخ الكود كله، والصقه في محرر Apps Script.
5. احفظ (Ctrl+S) وسمي المشروع أي اسم (مثلاً "KOPI API").
6. من فوق يمين: **Deploy (نشر) → New deployment (نشر جديد)**.
   - اضغط على أيقونة الترس ⚙️ بجانب "Select type" واختر **Web app**.
   - **Execute as (تنفيذ باسم)**: Me (حسابك انت).
   - **Who has access (مين يقدر يوصله)**: Anyone (أي حد).
   - اضغط **Deploy**.
7. جوجل هيطلب منك تصريح صلاحيات (Authorize) — وافق (هتظهر رسالة تحذير "Google didn't verify this app"، اضغط Advanced ثم Go to KOPI API (unsafe) — ده طبيعي لأنه سكريبت شخصي بتاعك).
8. هيديك رابط شكله كده:
   `https://script.google.com/macros/s/AKfycbx.../exec`
   انسخه، هتحتاجه في الخطوة الجاية.

> ⚠️ لو عدلت في كود `Code.gs` بعدين، لازم تعمل **Deploy → Manage deployments → ✏️ Edit → New version → Deploy** عشان التعديلات تتفعل على نفس الرابط.

---

## الخطوة 2: ربط الموقع بالرابط

1. افتح ملف `config.js` في مجلد الموقع.
2. استبدل `PASTE_YOUR_APPS_SCRIPT_URL_HERE` بالرابط اللي نسخته من الخطوة السابقة:

```js
const APPS_SCRIPT_URL = "https://script.google.com/macros/s/AKfycbx.../exec";
```

3. احفظ الملف.

## الخطوة 3: رفع المشروع على GitHub

1. اعمل حساب على [github.com](https://github.com) لو مالكش.
2. اعمل **New repository** (مثلاً اسمه `kopi-tracker`) — خليه Public أو Private (الاتنين شغالين مع Netlify).
3. ارفع كل ملفات المجلد ده (`index.html`, `style.css`, `app.js`, `config.js`) على الـ repo:
   - إما بالسحب والإفلات من واجهة GitHub مباشرة (**Add file → Upload files**)
   - أو باستخدام Git من جهازك:
     ```bash
     git init
     git add .
     git commit -m "أول نسخة من موقع KOPI"
     git branch -M main
     git remote add origin https://github.com/USERNAME/kopi-tracker.git
     git push -u origin main
     ```

---

## الخطوة 4: النشر على Netlify

1. اعمل حساب على [netlify.com](https://netlify.com) (تقدر تسجل دخول مباشرة بحساب GitHub بتاعك).
2. من الداشبورد: **Add new site → Import an existing project**.
3. اختر **GitHub** واختار الـ repo (`kopi-tracker`).
4. الإعدادات (بما إن الموقع static من غير build):
   - **Build command**: سيبه فاضي
   - **Publish directory**: `.` (النقطة، يعني نفس المجلد)
5. اضغط **Deploy site**.
6. بعد ثواني هيديك رابط شكله `https://random-name-123.netlify.app` — تقدر تغيره لاسم أوضح من **Site settings → Change site name** (مثلاً `kopi-cafe.netlify.app`).
7. ابعت الرابط ده للشركاء كلهم، وأي حد يفتحه هيشوف نفس البيانات لحظيًا.

> كل مرة تعمل push لتعديل جديد على GitHub، Netlify بيبني وينشر الموقع تاني أوتوماتيك.

## ملاحظات مهمة

- **"لحظيًا" هنا معناها**: أي إضافة من الموقع بتتكتب فورًا في الشيت. والموقع بيحدّث نفسه تلقائيًا كل 20 ثانية (تقدر تغيّر الرقم ده من `AUTO_REFRESH_MS` في `config.js`) عشان يجيب أي تعديل حصل في الشيت من حد تاني أو من الموقع. مفيش تحديث فوري بالميلي ثانية زي واتساب، لكن كافي جدًا لعدد شركاء محدود.
- **الحذف**: بيمسح بيانات السطر بس، مش بيشيل السطر فعليًا من الشيت (عشان معادلات الإجمالي متتبوظش).
- **حدود القالب**: الشيت مجهز مسبقًا لحد 200 سطر تقريبًا في كل شيت (المساهمات/المصروفات) و150 سطر في العهدة. لو قربتوا تخلصوا المساحة، قولي عشان أوسع الرينج في الكود والشيت.
- **الأمان**: أي حد معاه رابط الموقع يقدر يضيف/يعدل بيانات (مفيش تسجيل دخول). لو عايز حماية بباسورد بسيط قولّي أضيفهولك.
- لو غيرت أسماء الشيتات أو الأعمدة في الإكسيل الأصلي، لازم تعدل الأسماء المطابقة في أول كود `Code.gs`.
